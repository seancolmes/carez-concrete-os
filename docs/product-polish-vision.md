# Carez Concrete OS — Product Polish Direction

Target: professional, construction-native, low-friction software with the depth of a full estimating system and the speed of a modern browser takeoff tool.

## Product rules

1. Complexity belongs in the engine, not in the user's face.
2. Every screen should answer: What am I doing? What matters now? What is the next action?
3. Estimating and takeoff are trade-specific for concrete: slabs, footings, walls, curbs, sidewalks, steps, rebar, forms, pours and finishes.
4. One measurement should drive assemblies, labor, material, equipment, budget and field handoff.
5. Navigation should expose workflows, not database tables.
6. Mobile should feel like an app: bottom navigation, large touch targets, quiet hierarchy and minimal text density.
7. Desktop estimating should feel like a professional workspace: persistent context, dense tools when needed, and maximum drawing canvas.
8. Advanced controls are progressive disclosure; primary workflows stay obvious to a new user.
9. Readability wins over decoration. Dark UI remains construction-friendly but surfaces need stronger separation and calmer contrast.
10. Every route should reuse a shared visual language rather than inventing its own card/form system.

## Takeoff workspace target

- Immersive canvas mode.
- Wheel/pinch zoom with a high practical ceiling, cursor-centered zoom and fit-width / fit-page controls.
- Middle mouse / space-bar pan.
- Ortho and vertex snapping.
- Fast concrete assembly palette.
- Sheet navigation that can collapse to maximize plan area.
- Clean inspector with measurement, assembly inputs and generated quantities.
- Keyboard shortcuts, committed geometry undo/redo and repeated-takeoff workflows for estimators.
- Editable vertices, interior area cutouts, duplicate/nudge operations and a permanent resizable quantity worksheet.
- Future phases: PDF vector snapping, multi-select, overlays/revision comparison, text search, auto-count and batch scale/rename.

## App shell target

- Primary workspaces: Home, Estimate, Jobs, Field, Money.
- Context navigation shows only the active workflow's tools.
- Full module catalog lives behind More, not permanently on screen.
- Takeoff runs in immersive mode and gives the canvas priority.
- Mobile bottom navigation uses the same five mental models.
