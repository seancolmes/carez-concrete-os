# P0.5/P1 Builder Method Acceptance

Acceptance requires an explicitly verified build method before drawing or commercial readiness when an active Condition module contains safety-, scope-, or production-critical method assumptions that cannot safely default.

For the first strip-footing Company Condition Template, Carez must calculate 2x10 Douglas Fir form board in LF, form stakes in EA, and form labor from its production basis. A generic form-lumber/hardware material allowance is not part of the target Condition output.

Geometry edits preserve the exact Project Concrete Condition version and its method provenance. Changing a verified means/method or production assumption creates a new Condition revision or governed override event according to the canonical version contract. Plan facts, builder decisions, production assumptions, physical resources, commercial prices, and drawing presentation remain separate and traceable.

The estimator configures this through readable Condition module fields, toggles, dropdowns, and holds. Formula Composer is not part of the acceptance workflow.

All resulting resources and labor remain traceable from measurement role → Project Concrete Condition version → module/output → estimate item.
