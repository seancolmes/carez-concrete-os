# P1 Builder Method Acceptance

P1 acceptance requires a verified build method before drawing when an assembly contains active method or production assumptions.

For the first strip-footing builder recipe, Carez must calculate 2x10 Douglas Fir form board in LF, form stakes in EA, and form labor from its production basis. The legacy generic form-lumber/hardware material allowance is not part of the P1 target recipe.

Geometry edits must preserve the verified method profile. Changing a verified means-and-method or production assumption requires a new verified profile revision. Plan facts, builder decisions, production assumptions, physical resources, and commercial prices remain separate and traceable.
